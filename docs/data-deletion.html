ユーザーデータの削除手順

最終更新日：2026年8月11日

COMPASSION WORLD SNS CONTROLに保存されたFacebook、InstagramまたはThreads関連データの削除を希望する場合は、次の方法でご依頼ください。

削除依頼の方法

  1. 件名を「SNS CONTROL データ削除依頼」としてください。
  2. 対象となるブランド名、SNS名およびアカウントのユーザーネームを記載してください。
  3. wce.group06@gmail.comへ送信してください。

削除する情報

本人確認および管理権限の確認後、対象アカウントのアクセストークン、アカウント識別情報、投稿予定、投稿履歴および関連するエラー記録を削除または匿名化します。

処理期間

原則として、確認完了後30日以内に対応します。法令上の保存義務や不正利用調査等の正当な理由がある場合は、一部の情報を必要な期間保存することがあります。

Meta側での連携解除

Facebookの「設定とプライバシー」→「設定」→「ビジネス連携」から、本サービスの連携を削除することもできます。連携解除後は将来のAPIアクセスが停止します。
